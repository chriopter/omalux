# Assets

- `logo/omalux-logo.svg`: the existing Omalux wordmark copied from the website. `omalux-logo-light.svg` uses the UI foreground colour for dark backgrounds.
- `images/beach-volleyball.jpg`: the unchanged 1536 × 1024 AI-generated beach volleyball image from Omalux v0. Used when `bin/dev` receives no image argument. It is not a measured colour reference.

See [the original image notes](../omalux-v0/reference%20pictures/README.md) for provenance and the generation prompt. Reuse this file rather than regenerating it.
